# Codex Working Rules

You have permission to read any file in this repository/worktree without asking first.

You have permission to edit, create, refactor, rename, or move files within this repository/worktree when needed to complete the requested task.

Do not ask whether you are allowed to inspect project files. Assume file-reading permission is granted for the entire worktree.

Do not ask whether you are allowed to modify files. Assume edit permission is granted for the entire worktree.

Before making changes:

* Briefly inspect the relevant files.
* Make the smallest reasonable change that solves the task.
* Preserve existing style, naming, formatting, and architecture unless the task requires changing them.
* Avoid unrelated refactors.

You must ask for confirmation before deleting any file.

You may remove code inside a file when it is clearly obsolete or necessary for the requested change, but do not delete the entire file without explicit approval.

After making edits:

* Summarize what changed.
* Mention any files modified.
* Mention any tests, builds, or checks run.
* If you did not run tests, say so.

When a markdown file is created and the logic has all been implemented, move the markdown file into the `completed` directory within .ai
